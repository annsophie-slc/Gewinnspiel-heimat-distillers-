# Heimat Distillers – Gewinnspiel

Quiz-Gewinnspiel zum Vogelfrei-Video. Teilnahmen werden per E-Mail verschickt.

## 1. E-Mail-Adresse eintragen (wichtig!)

Öffne `index.html` und such ganz unten nach `EINSTELLUNGEN`. Ersetze dort

    EMAIL: "DEINE-EMAIL@example.de",

durch eure echte Adresse, z. B. `EMAIL: "messe@beispiel.de",`

## 2. Online stellen (GitHub Pages)

1. Neues Repository mit dem Namen **Gewinnspiel** anlegen (Public).
2. **Add file → Upload files**: `index.html` und `vogelfrei-video.mp4` hochladen,
   direkt auf die oberste Ebene, nicht in einen Ordner.
   Achtung: Die Datei muss exakt `index.html` heißen, nicht `index (1).html`.
3. **Settings → Pages** → Branch `main`, Ordner `/ (root)` → Save.
4. Nach 1–2 Minuten erreichbar unter `https://jovimarlen.github.io/Gewinnspiel/`

## 3. Einmalig freischalten

Der Versand läuft über den kostenlosen Dienst FormSubmit (ohne Anmeldung).

1. Die Seite selbst einmal komplett durchspielen und absenden.
   Beim ersten Mal erscheint eine Fehlermeldung, das ist normal.
2. FormSubmit schickt an eure Adresse eine Mail mit **Activate Form**. Klicken.
3. Ab jetzt kommt jede Teilnahme als E-Mail mit Name, E-Mail-Adresse und Antworten an.
   Schaut auch im Spam-Ordner nach.

## Testen

Nach einer Teilnahme merkt sich das Handy, dass es schon mitgemacht hat.
Zum erneuten Testen die Adresse mit `?neu` am Ende öffnen:
`https://jovimarlen.github.io/Gewinnspiel/?neu`
